# Son Koridor — Godot 4

Godot proje yöneticisinde **İçe Aktar / Import** seçeneğiyle bu klasördeki `project.godot` dosyasını seç. Projeyi açıp **F6 değil, F5** ile çalıştır.

WASD: hareket, fare: bakış, Shift: koşma, F: el feneri, E: etkileşim, Esc: duraklatma.

Koridorun sonunda sağdaki masadan anahtarı al, kırmızı ışıklı çıkış kapısına bakıp E'ye bas. Eşyalara yaklaşman ve onlara bakman gerekir.

Harici paket veya model gerektirmez. Godot 4, Compatibility renderer kullanır. Bu ilk prototipte hareket, çarpışma, fener, anahtar, kilitli çıkış, duraklatma ve yeniden oynama bulunur. Ses ve takip eden düşman henüz eklenmedi.
